# Вариант 6 — Этап 1: GUI-эмулятор оболочки

## Назначение

Проект реализует первый этап задания: графический прототип оболочки (REPL) с простым парсером команд, обработкой ошибок и командами-заглушками.

## Реализовано

- GUI-интерфейс на Tkinter.
- Заголовок окна в формате `Эмулятор - [username@hostname]`.
- Разбор команды на имя команды и аргументы, разделённые пробелами.
- Команды-заглушки `ls` и `cd`.
- Команда `exit`.
- Ошибка при неизвестной команде.
- Ошибка при передаче аргументов команде `exit`.
- Интерактивный ввод через поле ввода и клавишу Enter.
- Автоматическая прокрутка вывода.
- Набор unit-тестов для парсера.

## Требования

- Python 3.9+.
- Tkinter.

В стандартной установке Python Tkinter обычно уже доступен. В Linux при необходимости может потребоваться пакет `python3-tk`.

## Запуск

Из корня проекта:

```bash
./run.sh
```

или:

```bash
python3 src/main.py
```

## Проверка тестов

Если установлен pytest:

```bash
python3 -m pytest -q
```

## Сценарий демонстрации

Для проверки интерактивной работы можно выполнить:

```text
ls
ls file.txt test.txt
cd documents
cd documents projects
unknown
exit test
exit
```

Ожидаемое поведение:

- `ls` и `cd` выводят название команды и переданные аргументы;
- `unknown` выдаёт сообщение об ошибке неизвестной команды;
- `exit test` сообщает о неверных аргументах;
- `exit` закрывает приложение.
