# Чек-лист перед сдачей

1. Репозиторий создан на GitHub.
2. Загружены все файлы проекта.
3. В README описаны запуск и проверка.
4. Проверен запуск `python3 src/main.py`.
5. Проверены команды `ls`, `cd`, неизвестная команда и `exit`.
6. Запущены тесты `python3 -m pytest -q` (если pytest установлен).
7. Создан Git-коммит с понятным сообщением.
